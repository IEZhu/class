# Интеграция: перевод и дефиниции

> Этап 3 (S3-3, S3-4). Обслуживает попап клика по слову
> ([../flows/word-click.md](../flows/word-click.md)).

## Порядок источников при клике

1. **Кэш** — `terms.translation_cache` (jsonb): повторные клики бесплатны.
2. **Словарный датасет** (дефиниции) — локальный импорт открытых дампов
   (Wiktionary-извлечения / kaikki.org) в PG.
3. **LibreTranslate** — перевод en↔ru при кэш-миссе; результат — в кэш.
4. **DeepL Free** (500k знаков/мес) — «второе мнение» для редких/кривых слов.
5. **LLM-объяснение** — только по явной кнопке «объясни», с контекстом
   предложения (появляется в S5-8, см. [llm.md](llm.md)).

## LibreTranslate: конфиг

- Контейнер в compose (этап 3), **только** `--load-only en,ru`
  (иначе тянет все модели, RAM 1–1.5 GB и выше).
- Ограничить threads, чтобы не конкурировать с api за CPU.
- Интерфейс — внутренний HTTP из api; наружу не публикуется.
