# Интеграция: LLM

> Этап 5 (S5-6, S5-8). Один модуль с провайдер-абстракцией
> (Anthropic / OpenAI / DeepSeek) — конкретный провайдер выбирается конфигом.
> Реализация — `backend/internal/llm` ([ADR-029](../decisions.md)),
> генерация текстов и валидатор — `backend/internal/textgen`
> ([ADR-030](../decisions.md)).

## Задачи

| Задача | Где используется |
|---|---|
| Генерация текстов по словам: промпт {слова, CEFR, жанр, длина} | `POST /practice/generate-text` → `generated_texts` |
| Дистракторы для cloze | апгрейд cloze-генератора (S5-8) |
| Объяснения слов с контекстом предложения | кнопка «объясни» в попапе: `POST /terms/{id}/explain` → кэш `term_explanations` (S5-8, ADR-039, долг D-2 закрыт) |

## Провайдеры и ключи

Ключи `deploy/.env` (нужны только api):

| Ключ | Значение |
|---|---|
| `LLM_PROVIDER` | `anthropic` (по умолчанию) \| `openai` \| `deepseek`; другое — api не стартует |
| `LLM_API_KEY` | ключ выбранного провайдера; пусто — генерация отвечает 503 `llm_not_configured`, остальное работает |
| `LLM_MODEL` | пусто — самая дешёвая актуальная модель: `claude-haiku-5-5`, `gpt-6-luna`, `deepseek-flash` |
| `LLM_DAILY_LIMIT` | генераций на пользователя в сутки (UTC), пусто — 10 |
| `LLM_EXPLAIN_DAILY_LIMIT` | объяснений «объясни» на пользователя в сутки (UTC), свой счётчик; пусто — 30; ответ из кэша лимит не тратит |

| Провайдер | Вызов | Рассуждение модели |
|---|---|---|
| Anthropic | `POST https://api.anthropic.com/v1/messages`, `x-api-key`, `anthropic-version: 2023-06-01` | `output_config.effort: low` |
| OpenAI | `POST https://api.openai.com/v1/responses`, Bearer, `store: false` | `reasoning.effort: low` |
| DeepSeek | `POST https://api.deepseek.com/chat/completions`, Bearer | `thinking: {type: disabled}` |

Свой клиент на `net/http`, без SDK. Вызов — до 25 с, ответ — до 1 MiB,
текст — до 64 KiB. Генерация синхронная, в api: черновик и ретрай
укладываются в 55 с, хендлер продлевает себе таймаут записи. Ключ — только
в заголовке запроса, в журнал и ошибки не попадает.

## Промпт и prompt injection

Инструкции — системная часть из белых списков: уровень `A1`…`C2`, жанр
`story` | `dialogue` | `article` | `letter` | `description`, длина 50–400
слов. Слова пользователя — отдельным сообщением внутри `<target_words>`,
и инструкции называют список данными, а не командами. На границе каждое
слово проходит `lemma.IsWord` (только буквы, внутренние апостроф и дефис,
до 64 байт): фразу-инструкцию, тег или перевод строки в список не
передать. Слов — до 20, длина — не меньше 10 слов текста на слово. Ответ
модели — данные: хранится и показывается как простой текст.

«Объясни» (ADR-039, `backend/internal/explain`): системная часть
постоянна (ответ по-русски, два коротких абзаца — значение в предложении и
«Грамматика: …», до 80 слов, без markdown); форма слова, лемма и
предложение — в `<word>`, `<lemma>`, `<sentence>` как данные. Форма и лемма
проходят `lemma.IsWord`, предложение — до 1000 символов, обязано содержать
форму; управляющие символы и переводы строк в нём — пробелы, `<` и `>` —
`‹` и `›`. `max_tokens` 1024; ответ длиннее 1000 символов обрезается по
слову, рендер — абзацами через `<ClickableText>`. Гостю события
«объясни» нет (долг D-27).

## Валидатор покрытия (обязателен для генерации)

После генерации: лемматизация текста → каждое целевое слово встречается
**≥ 2 раз**; иначе ретрай с перечнем недостающих слов в промпте
(`<missing_words>`), один. Слово засчитывается цели, если у них общая
нормализованная форма или лемма (`internal/lemma`), составное — и по
частям. Только валидный текст сохраняется в `generated_texts`; провал
обеих попыток — 422 `coverage_failed` с недостающими словами. Отчёт —
покрытие, вхождения по леммам и доля слов вне словаря OEWN (без служебных
и целевых). Рендер — абзацами через `<ClickableText>`, как материал урока.

## Бюджет

Единицы $/мес ($2–5 в смете, [../06-budget.md](../06-budget.md)). Генерация
с ретраем — два вызова, до 2 × (4 × max_words + 1024) выходных токенов: на
Haiku 5.5 при 400 словах — до ≈ $0.0027. Суточный лимит держит потолок
около $45/мес при 55 людях (студенты и преподаватели, 10 генераций в сутки
каждый), у другого провайдера — ≈ 87 млн выходных токенов в месяц по его
цене (ADR-029). Объяснение — порядка $0.0003, его лимит добавляет к потолку
около $15/мес, а кэш по слову и предложению снимает повторы (ADR-039).
