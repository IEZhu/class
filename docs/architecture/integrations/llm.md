# Интеграция: LLM

> Этап 5 (S5-6, S5-8). Один worker-модуль с провайдер-абстракцией
> (Anthropic / OpenAI / DeepSeek) — конкретный провайдер выбирается конфигом.

## Задачи

| Задача | Где используется |
|---|---|
| Генерация текстов по словам: промпт {слова, CEFR, жанр, длина} | `POST /practice/generate-text` → `generated_texts` |
| Дистракторы для cloze | апгрейд cloze-генератора (S5-8) |
| Объяснения слов с контекстом предложения | кнопка «объясни» в попапе (S5-8, долг D-2) |

## Валидатор покрытия (обязателен для генерации)

После генерации: лемматизация текста → каждое целевое слово встречается
**≥ 2 раз**; иначе ретрай с перечнем недостающих слов в промпте.
Только валидный текст сохраняется в `generated_texts` и рендерится как
кликабельный материал.
