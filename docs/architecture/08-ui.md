# Интерфейс: токены, контраст, компоненты, правила (ADR-040)

Спецификация интерфейса `web/` после редизайна (ADR-040; запрос владельца — «сделай нормально, удобно и
красиво»): спокойное приложение для ежедневной учёбы — студенты практикуются с телефона, преподаватели ведут
уроки и группы с компьютера. Нумерация разделов — та же, что у рабочей спецификации редизайна: комментарии
кода ссылаются сюда как «DESIGN §N».

Где это в коде:
- `web/app/globals.css` — единственная таблица стилей проекта: токены (§2), сброс и база, классы
  компонентов (§3), каркас (§1.2); оглавление — в шапке файла;
- `web/app/ui/` — React-обёртки компонентов с разметкой и доступностью (кнопка, поле, сообщение, пустое
  состояние, шапка страницы, иконки, подсказка клавиши, статус, загрузка, время в поясе зрителя);
- `web/app/app-shell.tsx` — каркас с навигацией по роли (`app/user-bar.tsx` его реэкспортирует);
- стили одной страницы — CSS Module рядом с ней;
- `docs/architecture/ui/tokens.py` — цвета обеих тем и пересчёт контраста (§2.2).

Жёсткие ограничения:
- Только CSS: одна глобальная таблица (токены, база, общие классы) и CSS Modules для раскладок страниц. Без
  новых npm-зависимостей, веб-шрифтов и CDN (ADR-011, ADR-032). Иконки — свой набор inline SVG
  (`web/app/ui/icons.tsx`).
- Те же маршруты, вызовы api, данные и горячие клавиши. Любой текст по-прежнему идёт через `<ClickableText>`.
  Чисто интерфейсные добавки (якоря разделов, состояние раскрывашек, нижний лист, заголовки вкладок) api не
  трогают.
- WCAG 2.2 AA — базовый уровень; основные цели касания на страницах практики — 44px.

## 1. Информационная архитектура и навигация

### 1.1 Навигация по ролям

| Роль | Основные разделы (боковая панель / нижняя навигация) | Вторичные (низ панели / лист «Ещё») | Стартовая |
|---|---|---|---|
| Студент | Уроки `/lessons` · **Практика:** Словарь `/dictionary`, Карточки `/practice/cards`, Вставь слово `/practice/cloze`, Тексты `/practice/texts`, Видео `/practice/video` | Учётная запись `/account`, Выйти | `/lessons` |
| Преподаватель | Уроки · Люди и группы `/admin` · **Практика:** Тексты, Видео | Учётная запись, Выйти | `/lessons` |
| Админ | Уроки · Люди и группы | Учётная запись, Выйти | `/lessons`; пустое состояние ведёт в «Люди и группы» |
| Гость | Уроки (одно событие) | Учётная запись, Выйти | страница урока после входа по ссылке |

Правила: ссылки — те же, что были у прежней шапки (`user-bar.tsx`), только сгруппированы. Текущий пункт —
`aria-current="page"` (по префиксу `usePathname()`: `/lesson/…` — это «Уроки», `/practice/text` — «Тексты»).
Счётчика у «Карточек» нет: числа на странице нет, а ради него понадобился бы новый запрос к api. «Текст по
словам» `/practice/text` открывается из «Текстов» (кнопка «Сгенерировать текст»).

### 1.2 Каркас приложения

Десктоп от 1024px — боковая панель 248px закреплена, содержимое прокручивается:
```
+----------------------+--------------------------------------------------------------+
| [L] Lingua Class     |  ‹ Уроки                                     (крошка)        |
|                      |  H1 Заголовок страницы      <статус>   [главное действие]    |
| ▣ Уроки       (тек.) |  сведения · сведения                                         |
| ПРАКТИКА             |                                                              |
| ▢ Словарь            |  содержимое (колонка 720 / 960 / 1240px по типу страницы)    |
| ▢ Карточки           |                                                              |
| ▢ Вставь слово       |                                                              |
| ▢ Тексты             |                                                              |
| ▢ Видео              |                                                              |
|                      |                                                              |
| (АИ) Алексей Иванов  |   имя — до двух строк, без многоточия                        |
|      студент    [⇥]  |                                                              |
+----------------------+--------------------------------------------------------------+
```
Планшет 768–1023px — верхняя панель 56px: логотип, строка разделов и меню учётной записи (кнопка-аватар:
«Учётная запись», «Выйти»). В строке разделов — короткие подписи без иконок («Вставь», «Люди»), как в нижней
навигации, чтобы все пункты влезли в 768px. Если не влезли (крупный шрифт, интервалы текста), строка
прокручивается: текущий пункт после перехода прокручен в вид, край, за которым есть ещё пункты, гаснет.
Меню учётной записи закрывают Escape (фокус — на кнопку), клик мимо и уход фокуса из меню.

Телефон до 768px — верхняя панель (логотип и аватар) и нижняя навигация 64px плюс safe-area:
```
+--------------------------------------+
| [L] Lingua Class                (АИ) |   верхняя панель
+--------------------------------------+
|                                      |
|  содержимое, поля по 16px            |
|                                      |
+--------------------------------------+
| Уроки  Словарь  Карточки  Вставь  Ещё|   нижняя навигация (студент)
+--------------------------------------+
```
Нижняя навигация по ролям: студент «Уроки · Словарь · Карточки · Вставь · Ещё» («Ещё» — лист с «Текстами»,
«Видео», «Учётной записью» и «Выйти»); преподаватель «Уроки · Люди · Тексты · Видео · Ещё»; админ «Уроки ·
Люди · Профиль»; гость «Уроки · Профиль». Подписи не обрезаются: при крупном шрифте они переносятся, и панель
растёт. Лист «Ещё» — `role="dialog"`: фокус уходит в него и возвращается на «Ещё», Escape закрывает. Перед
навигацией — ссылка «К содержимому»; обе навигации — `<nav aria-label="Разделы">`.

Страницы без сессии (`/login`, `/invite/*`, `/join/*`, недействительные ссылки, 404 без входа) — **раскладка
входа**: карточка 400px по центру на `--c-bg`, логотип над ней, навигации нет. Ошибки и отказы для
вошедшего человека (урок не найден, нет доступа) — в каркасе, с действием «К урокам».

### 1.3 Заголовки вкладок (WCAG 2.4.2)
В корне `metadata.title = { default: "Lingua Class", template: "%s · Lingua Class" }`; у каждой страницы
свой заголовок: Вход, Уроки, название урока (`generateMetadata` страницы урока — тот же ответ api, что у
самой страницы, через `cache()`; у ошибок — «Нет доступа» и «Страница не найдена»), Мой словарь, Карточки,
Вставь слово, Тексты для практики, Текст по словам, Видео по словам, Учётная запись, Люди и группы,
Приглашение, Вход на событие, Страница не найдена.

## 4. Правила взаимодействия

### 4.1 Фокус и клавиатура
- Карточки: пробел и Enter переворачивают, 1–4 оценивают. Cloze: 1–4 выбирают вариант, после ответа Enter и
  пробел — дальше; в режиме ввода Enter отправляет ответ. Какие клавиши оставить полю ввода, слову и кнопке в
  фокусе, решает `lib/practice-keys.ts` (чистая функция, покрыта `npm test`). Все клавиши практики (пробел,
  Enter, 1–4) действуют, только пока фокус внутри сессии (WCAG 2.1.4): нажатие на ссылке меню или другой кнопке
  вне неё сессию не трогает.
- Сессия — `<section>` с `tabIndex=-1` и именем «Карточки» / «Вставь слово» (`aria-label`); фокус на ней
  виден кольцом `:focus-visible` (с клавиатуры, не после щелчка мышью; после загрузки страницы кольцо видно
  до первого щелчка — так браузер показывает фокус, поставленный кодом). Фокус переходит на сессию
  (`practice/session-focus.ts`), только когда он потерян — на `<body>`: после загрузки, после каждого шага и
  каждого запроса (и неудачного: нажатая кнопка на время запроса `disabled`; поле «Ввод слова» на это время
  `readOnly` и фокус не теряет, после сбоя он возвращается в поле), после щелчка по пустому месту
  страницы — полю, боковой панели, мимо попапа. Фокус, который человек поставил сам (ссылка меню, поле,
  кнопка), не забирается, даже если шаг закончился, пока он был там.
- Рядом с кнопками — подсказки клавиш (§3.22); на сенсорных экранах без клавиатуры их нет.
- Вкладки живого урока переключаются стрелками; Escape закрывает листы и меню, фокус возвращается на кнопку,
  которая их открыла; у попапа слова — по §4.2.
- Кольцо фокуса никогда не убирается; только `:focus-visible`, поэтому щелчок мышью его не рисует.

### 4.2 Попап слова (любой `<ClickableText>`)
- От 768px — поповер 360px у слова: координаты — CSS-переменные `--pop-top/--pop-left`, которые ставит JS
  (`lib/popover-place.ts`): под словом, если помещается, иначе над ним, иначе прижат к краю окна;
  `max-height: min(70vh, 560px)`, шапка липкая.
- До 768px — нижний лист (fixed, во всю ширину, скругление `--r-xl` сверху, ручка, `max-height: 78vh`) поверх
  затемнения; касание затемнения — «мимо», та же логика закрытия по `pointerdown`.
- Порядок: слово (24px) и форма / часть речи, «Закрыть»; перевод (18px); «В моём словаре» — пять сегментов
  статуса с номером и словом («1 новое … 5 знаю», `aria-pressed`), второстепенная «Объяснить», прозрачная
  красная «Убрать» справа; «+ В мой словарь», если слова в словаре нет; Значения; Примеры; атрибуция 12px
  (ссылки на лицензии остаются). Загрузка — три строки-заглушки; ошибка — красное сообщение.
- При открытии фокус уходит на заголовок попапа (tabindex -1): пока попап открыт, клавиши принадлежат ему. При
  закрытии изнутри (Escape, «Закрыть») фокус возвращается к слову (§5.2) — следующий Tab идёт от него; только
  попап, открытый мышью или касанием в сессии практики, отдаёт фокус сессии, чтобы горячие клавиши карточек и
  cloze работали дальше (`lib/word-nav.ts`, `closeFocusTarget`). Клик мимо попапа закрывает его, фокус — там,
  куда щёлкнули (пустое место на странице практики отдаёт его сессии, §4.1).
- «Убрать» спрашивает то же подтверждение, что и строка словаря (§4.4, `confirmRemove`): вместе со словом
  уходит его график повторений.

### 4.4 Обратная связь и обратимость
Опасные действия по-прежнему спрашивают `window.confirm`, выглядят как `.btn--danger-ghost` и не стоят рядом с
главным действием. Сообщения об успехе — `role="status"`, об ошибке — `role="alert"`.

### 4.5 Сторонние виджеты
- LiveKit: свой CSS `@livekit/components-styles` и `data-lk-theme="default"` (тёмная тема); контейнер со
  скруглением `--r-lg` на `--c-media-bg`, высота `min(70vh, 720px)`.
- Plyr: свой CSS; `--plyr-color-main: var(--c-primary)` на обёртке, обёртка — светлый остров (основной цвет
  светлой темы виден на тёмном видео в обеих темах); скругление `--r-lg`, `overflow: hidden`. На телефоне
  ползунка громкости нет (кнопка «Без звука» осталась) — ширина уходит полосе перемотки.
- Excalidraw: светлый в обеих темах (доска рисуется на белом) — светлый остров с рамкой и скруглением, высота
  `max(400px, 70vh)`.

## 5. Решения рядом с поведением (приняты при редизайне)
1. **Язык частей.** У корня `<ClickableText>` — `lang="en"`: все его тексты английские, русский перевод рядом
   лежит вне этого корня (WCAG 3.1.2).
2. **Слова с клавиатуры.** Блуждающий tabindex (roving tabindex) на блок текста: одна остановка Tab на `<ClickableText>`, ←/→
   переходят между словами, Enter и пробел открывают попап, слово — `role="button"`
   (`lib/word-nav.ts`). Обработчики клавиш карточек и cloze не забирают нажатие у слова (§4.1). WCAG 2.1.1.
3. **Учётная запись гостя.** У `role === "guest"` блока «Пароль» нет: пароля у гостевой учётки нет, форма
   могла бы только упасть.
4. **Местное время.** Время показывается в поясе зрителя: клиентский `ui/local-time.tsx`, сервер печатает UTC,
   после гидратации тот же `<time>` перерисовывается в поясе браузера (UTC — в `title`). Форматтеры
   `Intl.DateTimeFormat` создаются один раз на набор опций и пояс.

## 6. Раскладки страниц
Как страницы собраны из компонентов §3; ширина колонки — §2.5. Макеты редизайна (`lessons.html`,
`popup.html` и другие), на которые ссылаются комментарии некоторых CSS Modules, были рабочими материалами и в
репозиторий не вошли: вид страницы описан здесь.

### 6.1 Вход `/login` · Приглашение `/invite/[token]` · Вход на событие `/join/[token]`
Раскладка входа (§1.2): карточка 400px под логотипом, на телефоне — во всю ширину с полями 16px. Вход — e-mail,
пароль, «Войти»; ошибка — красное сообщение над кнопкой. Приглашение — кто и в какую группу приглашает, e-mail
приглашённого, задание пароля. Вход на событие — название, время, кто ведёт, предупреждение «Событие
записывается…». Недействительная ссылка — пустое состояние со ссылкой ко входу.

### 6.2 Уроки `/lessons` (720)
Шапка «Уроки» с «＋ Новое событие» у преподавателя (форма раскрывается карточкой под шапкой). Группы по фазе
`lessonPhase()` (подписи — `phaseTitles` из `lib/lesson-phase.ts`, не сырой статус api): «Сейчас», «Скоро» (по
возрастанию), «Прошедшие» (по убыванию). Строка — ссылка-карточка во всю ширину (≥64px): блок даты, название,
время, статус, бейдж открытого события. Админу — пустое состояние со ссылкой на «Люди и группы», гостю — его
событие.

### 6.3 Урок `/lesson/[id]` (1240)
- Шапка: крошка «‹ Уроки», h1 — название урока и статус фазы, дата и время (§5.4), преподаватель. У
  организатора открытого события справа (на телефоне — под заголовком) раскрывашка «Гостевая ссылка»: пока
  ссылки нет — раскрыта с «Выпустить ссылку»; сразу после выпуска — раскрыта с полем копирования; выпущенная
  раньше — свёрнута в строку с бейджем «Выпущена» (показать её снова нельзя: подсказка «Ссылку показываем один
  раз…», «Выпустить новую ссылку», «Отозвать»).
- Липкая строка якорей-чипов: «Класс» или «Запись», «Словарь урока · N», «Материалы · N», «Домашка · N»,
  «Участники · N», у преподавателя — «Подбор слов».
- Прошёл (запись): слева плеер Plyr 16:9, под ним — словарь урока (у студента — слова и подпись к подсветке;
  у преподавателя — карточка «Словарь урока» с кнопкой «Подбор слов»); справа — карточка «Транскрипт» во всю
  высоту экрана, со своей прокруткой и подсветкой звучащей реплики. «Кто говорит» (сопоставление меток ASR с
  людьми, только преподаватель) — свёрнутая раскрывашка в начале карточки: в заголовке число меток и сколько
  не указано. Уже 1024px — плеер, транскрипт (список до 60% экрана), словарь — друг под другом.
- Идёт сейчас: вкладки «Класс» / «Доска» над сценой `--c-media-bg` с приглашением «Войти в класс»;
  подключённый LiveKit и доска Excalidraw — в той же сцене.
- Запланирован — сведения «Урок начнётся …»; обрабатывается — предупреждение и заглушка плеера; завершён
  без записи — «Урок завершён. Записи у этого урока нет.».
- Ниже — материалы и домашка (карточки с текстом для чтения и файлами; у преподавателя — карточка «Добавить
  материал» с сегментами «Материалы | Домашка») и участники справа; у преподавателя после начала урока —
  карточка «Подбор слов»: таблицы кандидатов по источникам с общей сеткой колонок (☐ | слово | перевод | ×N; на
  телефоне ×N — под словом), липкое «Сохранить словарь урока (N)», свои слова, сбор с доски, назначение.
- Нет доступа и урок не найден — в каркасе: пустое состояние с «К урокам».

### 6.4 Попап слова
См. §4.2. Слова нет в словаре — «+ В мой словарь» вместо сегментов статуса; объяснение «Объяснить» — в рамке
`primary-soft`.

### 6.5 Мой словарь `/dictionary` (960)
Чипы-фильтры по статусу и подпись к подсветке слов; от 1280px — таблица (слово, перевод, статус, урок,
«Убрать»); уже — строки сеткой без шапки (на планшете и узком ноутбуке перевод под словом), на телефоне —
карточки. Статус — компактные сегменты 32px с шагом 8px (WCAG 2.5.8) и слово выбранного статуса рядом (в
таблице — в месте под самое длинное, «почти знаю»). «Убрать» — значок в конце строки, с подтверждением; сбой —
сообщением под строкой во всю её ширину. Листалка внизу.

### 6.6 Карточки `/practice/cards` (720)
Счётчик «N из M» и полоса прогресса, строка итога последней оценки (`role=status`), карточка: слово 36px,
после переворота — перевод, значения и пример с атрибуцией. Лицо — «Показать» с подсказкой «Пробел»; оборот —
«Снова 1 · Трудно 2 · Хорошо 3 · Легко 4» (цвет и всегда текст), на телефоне — сеткой 2×2.
Выдача пройдена или повторять нечего — пустое состояние.

### 6.7 Вставь слово `/practice/cloze` (720)
Счётчик, полоса прогресса, сегменты «Варианты | Ввод слова». Карточка: источник предложения, предложение 24px
с пропуском, четыре варианта (на телефоне 52px) или поле ввода 52px с «Проверить». После ответа выбранный и
верный варианты — с иконкой и текстом, остальные приглушены; итог (`role=status`) и «Дальше» с подсказкой
Enter. Варианты подбираются — четыре заглушки и «Подбираем варианты…»; сбой — предупреждение и «Повторить».

### 6.8 Тексты для практики `/practice/texts` (960) и Текст по словам `/practice/text` (720)
Тексты: «Сгенерировать текст» в шапке, поиск «Слова» с подписью и подсказкой, слова поиска чипами, карточки
текстов (свой текст — бейдж «Мой текст»; предложения Tatoeba — перевод и авторы мелко), листалка. Текст по
словам: карточка формы «Новый текст» (слова; уровень, жанр, длина — в строку, на телефоне друг под другом),
занятая кнопка «Генерируем…» с заглушкой, затем «Мои тексты»; покрытие слов и модель — в раскрывашке
«Подробности».

### 6.10 Учётная запись `/account` (720)

### 6.11 Люди и группы `/admin` (960)
Шапка с «＋ Пригласить», чипы-якоря «Люди · Приглашения · Группы · Архив». Карточка приглашения (имя, e-mail,
роль, группа, «Выпустить ссылку»; выпущенная — поле копирования). Таблицы людей (поиск по имени и e-mail —
фильтр уже загруженного списка), ждущих приглашений и архива; действия человека — раскрываемой строкой. Группы —
карточка на группу с участниками и добавлением по e-mail. Приглашения и архив до 1280px — строки-карточки (имя
сверху, колонки с подписями, кнопка справа); люди и прочие таблицы — карточками на телефоне. E-mail переносится
сперва после «@» и точек, посреди слова — только кусок шире колонки; в таблице приглашений и архива у колонки
адреса — своя наименьшая ширина. Преподаватель видит ту же страницу без управления ролями и группами и с
пояснением.
